# CaPa Webdesign Website

## Upload to GitHub + Vercel
1. Unzip this folder.
2. Create a new GitHub repository.
3. Upload all files from this folder, not the folder itself.
4. Import the repository in Vercel.
5. Deploy.
6. Add your domain in Vercel settings.
